# Mukammal xodim — yuklab olish

Bu yerda faqat dasturning tayyor `.exe` fayllari turadi (dastur kodi emas).
Dasturning o'zi shu yerdan yangi versiyani tekshiradi.

## O'rnatish

1. [Relizlar](../../releases/latest) bo'limidan `PerfectEmployee.exe` ni yuklab oling
2. Faylni ishga tushiring — o'rnatish shart emas, o'zi ochiladi
3. Birinchi ochilganda firma nomini kiritasiz

## Yangilanish

Dastur yangi versiya chiqqanini o'zi ko'radi va "Bosh sahifa" da xabar beradi.
Yangilashni siz tasdiqlaysiz. Ma'lumotlar (mijozlar, ombor, hujjatlar) saqlanib qoladi.
